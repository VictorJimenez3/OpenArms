# Research notes

Check the relevant notes for work already done. Save findings in your own folder ([Joseph](joseph/), [Stefanie](stefanie/), [Duc](duc/), or [Victor](victor/)). Update an existing note when it covers the same question.

Use the research question as the note title.

- **Finding** — What you learned and how it affects the demo.
- **Evidence** — Link to the source or include the command or setup and the result. Label tests as mocked, simulated, or on the physical arm where applicable.
- **Open question** — What is still uncertain or needs a decision.

Link the note in an issue or pull request when another teammate needs it. When the team agrees on a direction or interface, record the decision in [PROJECT.md](../docs/PROJECT.md) or [INTERFACES.md](../docs/INTERFACES.md) and link back to the evidence.
