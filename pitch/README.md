# Pitch, film and submission

Everything for HackPrinceton judging. Start with [TEAM.md](TEAM.md) for who does what by when.

| File | What it is |
| --- | --- |
| [TEAM.md](TEAM.md) | Schedule to the 8:00 a.m. cutoff and each person's lines, shots and table questions |
| [RECORD.md](RECORD.md) | **Start here to record your part: read along with your video in `prompter/`** |
| [SCRIPTS.md](SCRIPTS.md) | **Each speaker's lines and how to record the talking-head take and the opening skit** |
| [FILM.md](FILM.md) | The two-minute film: what we sell, timeline, exact voiceover, Ollie's animation plan, shot list, honesty rules |
| [JUDGES.md](JUDGES.md) | **How to close the pitch for each judge, and answers to the likely questions** |
| [FACTS.md](FACTS.md) | Statistics and numbers we can say out loud, with sources and the limits of each |
| [renders/submit-safe-v4.mp4](renders/submit-safe-v4.mp4) | Current cut, submittable as is: real arm, app and simulation footage, animated Ollie, script subtitles with a pacing dot. Speaker videos and voices drop in when recorded |
| [film/](film/) | HyperFrames source. Edit `build.py`, then `python3 build.py && npm run check` and `npm run render` (Node 22+, ffmpeg) |
| [scripts/](scripts/) | `capture_app_run.sh` records a full lab from the running student app; `clean_smartivity.py` re-renders recorded Smartivity episodes without burned-in captions |
| [DEVPOST.md](DEVPOST.md) | **Devpost copy, paste-ready, field by field** |

Send your talking-head take (`talk-<name>.mp4`), the skit and the music track to Victor; they go into the local drop folder and the final cut lands here.
