# OpenArms agents

> **Historical (HackPrinceton, November 2026).** This document is no longer maintained and may describe plans, scenes, owners or rules that no longer apply. [HANDOFF.md](../HANDOFF.md) is current. Where they differ, trust the code.

The application entrypoint is `python -m agentic.openarms_lab`. Follow the [runbook](../docs/LAB_RUNBOOK.md) for installation and configuration. `runtime.py` owns session state, review and consent. `task_loop.py` handles decisions, dispatch, and evidence checkpoints. `contracts.py` defines supported operations and `skills.py` owns admission and reuse. The default expert requests Codex `gpt-6.1-sol` at medium reasoning. Configured Gemini Live provides speech through the same session. [Expert profiles](../docs/EXPERT_MODELS.md)

The physical target is the selected two-vessel Smartivity A→C pour. MuJoCo is the active simulator and Isaac is parked. The current local integration supports the water-only carried-donor scene with `OPENARMS_EXECUTION=mujoco OPENARMS_SCENE=two_vessel`, fresh dispatch inspection and replay-backed skill admission. The default scene remains `metered_dropper`, an explicit `indicator_ph` regression apparatus. [The integration ledger](../docs/MAIN_INTEGRATION.md) records reviewed components and pending complete-loop acceptance. Physical execution remains disabled in this app. See [architecture](../docs/ARCHITECTURE.md), [interfaces](../docs/INTERFACES.md), and the [R1–R6 acceptance contract](../docs/FULL_SYSTEM_DELIVERY.md). Optional prediction/reflection never gate control.

`openarms_agent`, its original Claude prompts and older `scripts` are preserved research/fallback components, not an alternate application entrypoint. Do not start a second dispatcher or registry when integrating new capabilities. Firmware and recorded physical evidence retain their separate supervision and authorization requirements.

Run `agentic/scripts/full_loop_rehearsal.py --execution mujoco --scene two_vessel` for real expert skill authoring and warm reuse on the water scene, or select `--scene metered_dropper` for the indicator fixture. Each run needs a fresh `--out` directory. Run `agentic/scripts/student_decision_rehearsal.py` to compare expert decisions on clear and obscured synthetic images. See [Victor's handoff](../research/victor/devin-handoff.md) for the setup, evidence and verification commands.

Victor is the [agentic owner](../AGENTS.md#ownership). His [student and agent flow handoff](../research/victor/student-and-agent-flow.md) covers the current gaps, lab setup changes and first tests.
