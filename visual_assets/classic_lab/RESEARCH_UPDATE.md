# Six classic laboratory asset candidates

The visual scope is now six recognizable laboratory procedures: serial dilution, titration, unknown color comparison, stirred-versus-still dissolution, paper filtration, and precipitation with a water control. These replace the earlier friction, lever and elementary manipulation candidates. The presentation remains a practical bench with one experiment at a time, a white original SO-101, and external fixed cameras.

Six Astra High experiment artists generated independent Blender geometry and scene sources. The coordinating agent reviewed the actual renders, corrected obscured liquid colors, framing and labels, and moved the filtration apparatus clear of an observed static-arm overlap. Each scene provides front, overhead and result views, an editable Blender project, a self-contained robot-free USD environment, physical dimensions and proposed interaction interfaces. The shared contract is meters, Z-up, tabletop z=0, default prim `/ClassicLab`.

Each candidate has a student-controlled variable, two intended conditions, and an observable. The precipitation candidate maps A/B to the familiar calcium-chloride/sodium-carbonate calcium-carbonate demonstration; its materials remain illustrative, not a reaction solver. [University of Colorado demonstration reference](https://www.colorado.edu/lab/lecture-demo-manual/general-reactions/s130-chemical-rxns-precipitation-cacl2-na2co3-caco3).

All 18 images are actual Blender renders. Saved USD checks verify units, default prim, finite geometry, camera presence, materials, dependency closure and no authored physics; fresh Blender imports check all six environments. Explicit opacity fallbacks repair Blender transmission/mixed shaders that otherwise export as opaque. Target Isaac rendering still requires inspection, particularly transparent vessels, liquid appearance, exposure and view occlusion.

These are visual assets and interaction specifications, not six completed simulations. Rendered color changes, suspended/remaining solids, droplets, instrument readings and timer values are staged. Science models, resets, contact-qualified fixtures/controllers, application backend registration, actual execution and held-out harness evaluation remain outstanding. No physical laboratory result or learning improvement is claimed. The independent, verified two-mass Isaac experiment remains separate evidence and did not use these scenes; see the [earlier runtime evidence update](https://github.com/VictorJimenez3/OpenArms/blob/visual/accessible-lab/research/joseph/training-scene-evidence-2026-11-14.md).
